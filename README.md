## 🎯 如何使用

每个子文件夹独立完整，包含：

- `README.md`：本篇的复刻目标、数据来源、分析步骤
- `scripts/`：带详细注释的R/Python脚本
- `results/`：生成的SCI标准图表（PDF+PNG）
- `references/`：原文PDF及补充材料

**运行方式**：进入子文件夹后，按脚本编号顺序执行。
